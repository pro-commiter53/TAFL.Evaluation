What is a PDA?

A Pushdown Automaton (PDA) is a computational model that extends a finite automaton with an auxiliary stack. This stack gives the PDA unlimited memory, allowing it to recognize context-free languages — a strictly broader class than regular languages.

At each step, the PDA reads an input symbol, examines the stack top, and — based on a transition function — changes state and pushes or pops symbols.

M = (Q, Σ, Γ, δ, q₀, Z₀, F)
Q — finite set of states
Σ — input alphabet
Γ — stack alphabet
δ — transition function
q₀ — initial state
Z₀ — initial stack symbol
F — set of accept states
