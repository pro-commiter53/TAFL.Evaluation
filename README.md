## 📌 About the Project

This project is a web-based simulator built as part of the **Theory of Automata and Formal Languages** course. The aim is to understand how a Pushdown Automaton (PDA) works by visualizing its step-by-step execution.

Instead of just studying definitions and examples on paper, this simulator shows how input strings are processed, how the stack changes, and how transitions take place between states.

---

## ⚙️ Tech Stack

The project is built using basic web technologies:

* **HTML** – for structuring the interface
* **CSS** – for styling and layout
* **JavaScript** – for implementing the PDA logic and simulation

No external libraries or frameworks have been used.

---

## 📂 File Structure

The repository contains the following files:

* `index.html` → Main structure of the web application
* `style.css` → Styling (layout, colors, fonts, UI design)
* `script.js` → Core logic of the PDA simulation

All files are directly placed in the root directory for simplicity.

---

## 🧠 What the Project Does

The simulator allows the user to:

* Enter an input string
* Select a language (like aⁿbⁿ, balanced parentheses, wcwᴿ)
* Run the simulation step-by-step
* Observe:

  * Current state
  * Stack operations (push/pop)
  * Transition function used
* Get final result: **Accepted or Rejected**
